# JOMAPZ

A personal and family turn-by-turn navigation app for Android, built for Malaysian roads.

**Created and owned by Pratama Yudha.** Copyright (c) 2026. All rights reserved. This is not open source: copying, redistributing or presenting this app or its code as your own is not permitted (see `LICENSE`).

## What it does
- Search and turn-by-turn navigation (car and motorcycle), voice guidance in Malay or English
- Speed display, speed-limit sign, overspeed warning
- Lane guidance where OpenStreetMap lane data exists
- Alerts for speed cameras, traffic lights, tolls, rest areas, road closures
- Auto day/night map, auto-zoom by speed, heading-up map
- Saved places, trip recording, share ETA, background running with a shutdown button
- In-app update check

## Data and services
- Map and road data: OpenStreetMap contributors (ODbL)
- Routing: Valhalla (FOSSGIS public server); search: Photon (Komoot)
- Road closures: TomTom Traffic API (optional, user's own key)
- Map rendering: MapLibre GL JS; app shell: Capacitor
